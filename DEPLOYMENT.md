# 🚀 JanSetu AI — Render Cloud Hosting & Deployment Guide

This guide walks you through deploying **JanSetu AI** to **[Render](https://render.com/)** in under 5 minutes.

---

## 🌟 Why Render?
- **Free Tier Available**: Deploy web services at $0 cost.
- **Unified Engine**: Our `server.js` boots **Backend API**, **Citizen Public Web**, **Authority Command Web**, and **WhatsApp Bot** together in a single Web Service!
- **Zero CORS / Mixed Content Issues**: All portals and APIs share the same domain (`https://jansetu-ai.onrender.com`).
- **Automatic HTTPS**: SSL certificates are generated automatically.

---

## 📋 Prerequisites
1. A GitHub account with the **JanSetu AI** repository pushed.
2. A free account on **[Render.com](https://render.com/)**.
3. A Google Gemini API Key from **[Google AI Studio](https://aistudio.google.com/)**.

---

## ⚡ Method 1: The Easiest 1-Click Deployment (Recommended)

### Step 1: Push your code to GitHub
Make sure all your changes are committed and pushed to your GitHub repository:
```bash
git add .
git commit -m "Render ready unified deployment"
git push origin main
```

### Step 2: Create a New Web Service on Render
1. Log in to **[dashboard.render.com](https://dashboard.render.com/)**.
2. Click the **"New +"** button in the top right corner and select **"Web Service"**.
3. Choose **"Build and deploy from a Git repository"** and click **Next**.
4. Connect your GitHub account and select your **`jansetu-ai`** repository.

### Step 3: Configure the Web Service
Fill in the configuration fields:

| Field | Value |
|---|---|
| **Name** | `jansetu-ai` *(or any unique name you prefer)* |
| **Region** | Select the region closest to your users (e.g. `Singapore` or `Oregon`) |
| **Branch** | `main` |
| **Root Directory** | Leave empty *(default is root)* |
| **Runtime** | `Node` |
| **Build Command** | `npm install` |
| **Start Command** | `npm start` |
| **Instance Type** | `Free` ($0/month) |

### Step 4: Add Environment Variables
Scroll down to the **"Environment Variables"** section and click **"Add Environment Variable"**:

| Key | Value | Description |
|---|---|---|
| `NODE_ENV` | `production` | Production mode |
| `GEMINI_API_KEY` | `AIzaSy...` | Your Google Gemini API Key from AI Studio |
| `GEMINI_MODEL` | `gemini-2.5-flash` | Gemini Model (e.g., `gemini-2.5-flash`) |
| `JWT_SECRET` | `jansetu_prod_secret_2026_xyz` | Any secure random string |

*(Optional variables like `NITI_API_KEY` or `WHATSAPP_PHONE` can be added if needed).*

### Step 5: Deploy!
1. Click **"Create Web Service"** at the bottom of the page.
2. Render will build and deploy your app automatically.
3. In 2–3 minutes, you will see:
   ```
   ==> Your service is live 🎉 at https://jansetu-ai.onrender.com
   ```

## ⚡ Method 2: Blueprint Deployment (`render.yaml`)

If you prefer Infrastructure as Code:
1. Go to **Render Dashboard** -> **New +** -> **"Blueprint"**.
2. Connect your GitHub repository.
3. Render will automatically detect the **`render.yaml`** file in your repo.
4. Enter your `GEMINI_API_KEY` when prompted.
5. Click **"Apply"** — Render configures and deploys everything automatically!

## 📱 WhatsApp Bot in the Cloud

- Our unified server automatically boots the WhatsApp microservice in the background.
- To view the WhatsApp QR code when setting up on Render:
  1. Open your service in the **Render Dashboard**.
  2. Click **"Logs"**.
  3. You will see the terminal QR code generated by the WhatsApp bot.
  4. Open WhatsApp on your phone -> **Linked Devices** -> **Link a Device** -> Scan the QR code displayed in the Render log stream.
  5. The session connects and is ready to deliver live status updates!

## 💡 Pro Tips for Render Free Tier
- **Cold Starts**: Render's free tier spins down web services after 15 minutes of inactivity. When a new request arrives, it may take ~30-50 seconds to spin back up.
- **Keep-Alive**: To prevent spin-downs during hackathon judging, you can use a free pinging service like [UptimeRobot](https://uptimerobot.com/) to ping `https://your-app.onrender.com/health` every 5 minutes.
